# פרטיות: מי יכול לראות מידע של הלקוח, ולמה

המסמך כתוב בעברית פשוטה, כדי שבן יוכל לקרוא אותו.

## מי רואה מה באפליקציה

- **בן (בעלים) וחשבון המפתח (אדמין):** כל הפרויקטים, הכספים, המסמכים והיומנים, וניהול ההרשאות. רק בעלים או אדמין מוסיפים או מסירים גישה.
- **מנהל פרויקט ועובד:** רק הפרויקטים שבן שייך אותם אליהם. מנהל רואה כספים רק אם בן פתח לו את זה בפרויקט.
- בפרויקט שהסתיים אפשר רק לצפות ולהדפיס.

## חשבון המפתח (אלון, פיתוח ותמיכה)

- חשבון שנקרא **"Alon (Developer & Support)"** מופיע ברשימת האנשים, גלוי לבן ואינו מוסתר.
- הוא חשבון ברמת בעלים ("אדמין"): רואה את כל הפרויקטים, הכספים והמסמכים, כדי לבדוק תקלות ולתמוך.
- בנוסף, למפתח יש גישה טכנית לשירותי המערכת (Supabase ו-Vercel), ובעיקרון גם למסד הנתונים עצמו. זה נחוץ לתחזוקה, לגיבוי ולשחזור, ובמיוחד לאיפוס סיסמת בן.
- כל גישה של המפתח לנתוני הלקוח מעבר לשימוש הרגיל באפליקציה נרשמת ב-[OPERATIONS](OPERATIONS.md).
- כל בעלים או אדמין רשאי להשבית או להוריד הרשאה לבעלים אחר, לכן בן יכול להשבית את חשבון המפתח בכל עת. את הבעלים האחרון אי אפשר להסיר. ההשבתה חוסמת את הכניסה לאפליקציה, ולא את הגישה הטכנית לשירותים.

## איפה המידע נשמר

- מסד הנתונים והקבצים: Supabase, פרויקט באירלנד. האפליקציה: Vercel. הגיבויים: Supabase (תוכנית Pro).
- אין שירות מיילים, ואין מעקב או פרסום.

## מידע אישי של אנשי קשר

אנשי קשר באתרי הבנייה נשמרים רק בפרויקט שלהם ונראים רק למי שמורשה לפרויקט.
