## מה נבנה

- `createUsersApi(platform)` מחבר queries ו-commands עם הצהרת `satisfies UsersApi`. כל פעולה בודקת בעלות חיה דרך Platform לפני נתונים או תופעות לוואי.
- קריאת משתמשים, חיפוש מנורמל, פרטים, שיוכים ורשימת חברי פרויקט עם דפדוף מלא של Data API וסדר יציב. נתונים נשלפים ב-JWT משתמש וב-RLS.
- יצירה עם fullName ו-requestId דרך authAdmin הקיים; קבלת Saved מקריאת פרופיל, בלי סיסמה ב-RPC. איפוס דרך authAdmin בלבד. השבתה, שיוך, הסרה וכספים דרך RPC עם revision מהלקוח, בלי retry אוטומטי של conflict.
- `updateUser` (שם ואימייל) מועבר ל-`authAdmin.setEmail` עם revision מהלקוח; CONFLICT/VALIDATION חוזרים כפי שהם, בלי retry.
- `actions.ts` מסומן use server, מפיק context מהשרת, מאמת סכמות strict ומחזיר Result. שאר הלוגיקה server-only. אין מסכים, סכמה, חוזים, תשתית, תלויות, CI או שירותים חדשים.
