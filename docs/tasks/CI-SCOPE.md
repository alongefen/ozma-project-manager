# CI-SCOPE — התאמת בדיקות להיקף השינוי

22.11.2026. המימוש עבר סקירה עצמאית והתיקון הממוקד אומת, ללא ממצא פתוח; ללא ריצה מרחוק.

## תוכנית ומימוש

- נוסף מסווג Node ללא תלויות. ב-PR הוא בודק את ההפרש בין merge-base לראש הענף; ב-push את before/after המלאים. טווח חסר, קומיט שאינו זמין, merge-base עמום או הפרש ריק מחזירים מסלול בדיקות מלא.
- תיעוד מוכר בלבד: `AGENTS.md`, `README.md`, קובצי `.md` תחת `docs/`, `supabase/README.md` ו-`src/features/reports/assets/README.md`. Markdown אחר תחת `src` או נתיב לא מוכר מפעילים בדיקות מלאות.
- רשימת הקבצים מתקבלת עם מפריד NUL וללא זיהוי renames: שינוי שם מקוד לתיעוד כולל גם את מחיקת נתיב הקוד ולכן אינו מדלג על בדיקות.
- ה-job `foundation` ושם ה-check הקיים נשמרו ללא סינון `paths`. הסיווג מופעל לפני setup והתקנה. בתיעוד בלבד אין התקנת תלויות, lint, טיפוסים, build או tests; ה-job מסתיים בהצלחה ומדווח את הסיבה. שינוי מעורב, קוד, הגדרות או כשל בסיווג מפעילים את מסלול הבדיקות הקיים, בתוספת בדיקות המסווג הממוקדות.
- לא השתנו תלויות, בדיקות מסד או workflow הענן. בדיקות הענן נשארות כבויות לפי ההחלטה הקודמת.

## בדיקות ותוצאות

- `node --test .github/scripts/change-scope.test.mjs`: 18 בדיקות עברו ללא דילוג, מול מאגרי Git זמניים עם נתונים בדויים. נבדקו תיעוד מוכר, שינוי מעורב, Markdown לא מוכר, workflow ותלויות, מחיקה, שינוי שם מקוד לתיעוד, PR שבסיסו התקדם, push עם כמה קומיטים ושינוי שבוטל, שם קובץ עם ירידת שורה וטווחים חסרים או לא תקינים. נוספה בדיקת תנאי ה-workflow: כשל מסווג לאחר פלט `docs_only=true` עדיין מפעיל את כל שמונת שלבי הקוד.
- תחביר YAML ו-`git diff --check`: עברו.
- לא הופעל GitHub Actions, ולא הורצו בדיקות מוצר, מסד או build שלא הושפעו מהשינוי. התנהגות הסיווג נבדקה מקומית; אימות מרחוק טרם בוצע, ומידע המכסה אינו נגיש בחיבור הנוכחי. זהו חוסר מידע בלבד; נשמרו runner רגיל ו-timeout של 15 דקות ללא שינוי תשלום או תקציב, ואין בכך שער הגשה חדש.

## סקירה עצמאית

הסוקר בדק את ההפרש, YAML, קלט CLI תקין ושגוי ותנאי ה-workflow. נמצא שהמסווג יכול לכתוב `docs_only=true` ואז להיכשל בכתיבת summary. תוקנו כל תנאי שלבי הקוד כך שכשל מסווג תמיד מפעיל אותם, גם אם הפלט כבר נכתב. בדיקת regression ממוקדת עברה; הסוקר אימת את הדלתא: שמונת התנאים מול 15 שילובים, YAML ו-CLI, ללא ממצא פתוח.
