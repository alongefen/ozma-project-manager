## What changed

- `/` (home): counters, project cards with badges (status, open tasks, reports), and the finance cube for the owner only. Phone: counters grid, cube, cards. Desktop: counters row, project grid, summary column with the cube.
- `/finance`: all-projects transfer summary (owner only). Phone: one card per month with the transfer amount, project breakdown opens under it. Desktop: one table, months newest first, projects under each month. `loading.tsx` added.
- Data comes from the existing `OverviewApi` (`getHome`, `getTransferSummary`) through `shared/load.ts`; no calculation in views (`shared/view-model.ts` only formats and orders).
