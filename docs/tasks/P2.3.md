Create keeps its request id only after an ambiguous failure (lost answer).
- `TasksMobile` (new-note button, open group, collapsible done group, no tabs) and `TasksDesktop` (title row, two panels with a card grid from 1024). Shared `TaskCard`, `TaskGroup`, `TaskForm` (note up to 2,000 with counter, optional due date), `model.ts` (pure list changes, due wording, draft validation).
- Controls follow the live permission: `canWrite` for create/edit/tick, `canWrite && isOwner` for delete. On a finished project: read-only notice, disabled ticks, no buttons. Group counts are list lengths of fully loaded lists; the server counts are not displayed.
- Deviation from DESIGN S09: phone create/edit is the shared bottom sheet, not a full screen (UI_CONVENTIONS "Pop-up = Sheet").
