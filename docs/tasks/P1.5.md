# P1.5 — two shells, base components and sign-in

23.11.2026. Branch `claude/p1-5-shells-1fa729`. Gates: G2 passed (A-40), GU approved (A-24); neither reopened. No migration, service, cost or deployment.

## What changed

- **Two shells over the same routes** (`src/app/(app)/layout.tsx`). Page content is rendered once. Phone chrome (`components/shell/mobile`: header, bottom nav) and desktop chrome (`components/shell/desktop`: sidebar, header) are separate components, switched by CSS at 1024 (phone up to 1023, desktop from 1024, DESIGN 4).
- **Phone:** bottom navigation with an odd item count and "דיווח חדש" as the raised middle button; owner: projects, diary, **report**, finance, more; everyone else: projects, **report**, diary. No sidebar, no tab bar (UX-19). Non-owners reach their account from the header avatar, the owner from "עוד".
- **Desktop:** demo sidebar (230, 195 from 1024 to 1100), header with breadcrumb, account name and sign-out on the left.
- **Sign-in / sign-out** (`features/auth`): email as username, one generic failure text, no 2FA, no email service. Full-screen on phone, 420px white card on desktop. Signed-out requests to `(app)` redirect to `/sign-in`; a signed-in visit to `/sign-in` goes to `HOME_PATH`.
- **"עוד"** (`(app)/more`, `features/more`): account block, owner-only links (workers, project archive, action log), sign-out on phone.
- **Base components** (`components/ui`): Button, TextField (password show/hide, LTR for email), Card, Badge, Notice, Avatar, Icon. Plain CSS in `src/styles/app.css` using the demo tokens; no Tailwind utilities.
- **Upload** (`components/upload`): `FileUpload` (begin, resumable TUS, complete over the P1.3 routes), plus `rules.ts` pre-checks (50MB documents, 25MB diary/cover, one cover, 20 files). Consumers pass `purpose` and `projectId`.
- `src/lib/navigation.ts` (pure nav model), `src/app/manifest.ts` and `public/icons` (UX-15), self-hosted Assistant font (`src/fonts`), logo `public/brand/logo.webp` (the approved temporary logo).
- `(app)/projects/[id]/layout.tsx` only rejects malformed ids; no chrome.
