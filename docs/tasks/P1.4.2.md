## מה נבנה

- כל פעולות `ProjectsApi`: רשימה עם חיפוש מנורמל וסינון משולב, פרטים, יצירה ועדכון, סיום ופתיחה מחדש, ארכיון ותמונת שער.
- קריאת פרטים עם JWT המשתמש ו־RLS. מספר חברה מוחזר לבעלים בלבד; שמות מנהלים נקראים ב־RPC הקיים. רשימת הכרטיסים היא צבירת JSON מלאה במסד, ללא חיתוך במגבלת שורות ה־Data API.
- כתיבה רק בפונקציות המסד הקיימות, ששומרות על הרשאות חיות, גרסאות וניסיון חוזר. קלט נבדק בסכמות הממוזגות; Server Actions מקבלות הקשר מהשרת.

אין מסכים, מיגרציה, שינוי חוזים או תשתית משותפת, תלויות, שירות חדש או פריסה. אין איפוס או מחיקת נתוני בדיקה.
